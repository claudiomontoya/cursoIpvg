Slide 3 · Flujo

Qué pasa cuando preguntás algo

Ejemplo: "¿Cuántas inasistencias puedo tener antes de reprobar?"

1
El usuario envía la pregunta El navegador hace POST a /api/chat con el texto
2
Runner.run() arranca el agente Una sola línea ejecuta todo el ciclo IA — antes eran ~120 líneas a mano
3
GPT-4.1 decide usar la tool buscar_reglamento Las instrucciones le dicen que para temas normativos siempre la use
4
El MCP server busca en el PDF y devuelve el artículo Retorna texto + número de artículo + página
5
GPT redacta la respuesta final citando la fuente FastAPI la envía al navegador junto con el detalle de qué tools usó
Slide 4 · Código

Las funciones clave del archivo

Todo el sistema cabe en menos de 140 líneas

Función / Concepto
Qué hace
lifespan()
Abre la conexión MCP al arrancar y la mantiene viva para todas las requests.
Agent(...)
Define el "trabajador" IA: modelo, instrucciones y qué tools tiene disponibles.
Runner.run()
Ejecuta el agente y resuelve solo el loop pregunta → tool → respuesta.
extraer_tools()
Auditoría — devuelve qué herramientas usó el agente y con qué argumentos.
/api/chat
El endpoint que recibe la pregunta del navegador y devuelve la respuesta + trazabilidad.
